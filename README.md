# aasp-dev Homebrew tap

```sh
brew install --cask aasp-dev/tap/title-switcher
```

| Cask | App |
| --- | --- |
| `title-switcher` | [TitleSwitcher](https://github.com/aasp-dev/title-switcher): keyboard-driven window switcher for macOS |

Casks are updated automatically by each app's release workflow.
